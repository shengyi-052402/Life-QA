# 部署说明

## 目标

本项目当前支持以下运行形态：

- 开发环境：前端 `Vite` + 后端 `Spring Boot` + 本地 MySQL
- 生产环境：前端静态资源 + 后端 Jar + MySQL 8 + Elasticsearch 8

第三优先级已完成到“可部署”层面：

- 已补 `application-prod.yml`
- 已补环境变量模板 `.env.example`
- 已补 Docker Compose 示例 `deploy/docker-compose.prod.yml`
- 已补 Nginx 反向代理配置 `deploy/nginx/forum.conf`

## 一、生产环境要求

- JDK 17
- Node.js 20+
- Maven 3.6+
- MySQL 8.0
- Elasticsearch 8.x
- Nginx 1.24+

## 二、关键环境变量

后端生产环境必须提供以下变量：

```bash
SPRING_PROFILES_ACTIVE=prod
DB_URL=jdbc:mysql://127.0.0.1:3306/forum?serverTimezone=Asia/Shanghai&useUnicode=true&characterEncoding=utf-8&zeroDateTimeBehavior=convertToNull&useSSL=false&allowPublicKeyRetrieval=true
DB_USERNAME=forum
DB_PASSWORD=change-me

FORUM_UPLOAD_PATH=/data/forum/uploads/
FORUM_UPLOAD_URL_PREFIX=/uploads/

FORUM_SEARCH_ES_ENABLED=true
ES_URIS=http://127.0.0.1:9200
FORUM_SEARCH_ES_INDEX=forum_posts
```

可选 OSS：

```bash
OSS_ENDPOINT=
OSS_ACCESS_KEY_ID=
OSS_ACCESS_KEY_SECRET=
OSS_BUCKET_NAME=
OSS_DOMAIN=
```

## 三、后端部署

### 1. 打包

```bash
cd forum
mvn -DskipTests package
```

产物默认位于：

- `forum/forum-server/target/forum-server-1.0-SNAPSHOT.jar`

### 2. 启动

```bash
java -jar forum-server-1.0-SNAPSHOT.jar --spring.profiles.active=prod
```

## 四、前端部署

### 1. 打包

```bash
cd forum-web
npm install
npm run build
```

产物默认位于：

- `forum-web/dist/`

### 2. Nginx 部署

将 `forum-web/dist` 放到 Nginx 静态目录，将 [forum.conf](../deploy/nginx/forum.conf) 作为站点配置。

当前代理规则：

- `/` -> 前端静态资源
- `/api/` -> `forum-server:8080`
- `/uploads/` -> `forum-server:8080`

## 五、Elasticsearch 启用流程

### 1. 启动 ES

确认 `ES_URIS` 指向可用实例，例如：

```bash
curl http://127.0.0.1:9200
```

### 2. 打开 ES 搜索

设置：

```bash
FORUM_SEARCH_ES_ENABLED=true
```

### 3. 重建索引

启动后端后，使用管理员账号进入后台首页，点击“重建搜索索引”。

这样会把历史帖子全量写入 ES 索引。

## 六、Docker Compose 示例

仓库已提供：

- [docker-compose.prod.yml](../deploy/docker-compose.prod.yml)

启动方式：

```bash
cd deploy
docker compose -f docker-compose.prod.yml up -d
```

说明：

- `mysql`、`elasticsearch`、`forum-server`、`forum-web` 都已给出示例
- `forum-server` 默认读取 `prod` 配置
- 需要先完成后端 Jar 打包和前端 `dist` 构建

## 七、上线前检查

- 修改所有数据库与 OSS 密钥，不使用默认示例值
- 确认 `application-dev.yml` 中无真实密钥
- 确认上传目录有持久化挂载
- 确认 MySQL 已执行 `init.sql`、`notification.sql`、`v3_post_location.sql`
- 确认 ES 可连通，并完成一次全量重建索引
- 确认 Nginx 已放开前端路由回退到 `index.html`

## 八、当前已知限制

- Docker Compose 示例主要用于单机部署，不是高可用方案
- ES 开启后仍保留数据库回退逻辑，但生产环境应优先确保 ES 稳定可用
- 前端仍有较大的打包体积告警，后续可继续做 chunk 拆分优化
