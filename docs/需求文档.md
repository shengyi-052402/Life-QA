# 论坛网站 — 需求文档

> 文档版本：v1.0  
> 创建时间：2026-04-15  
> 最后更新：2026-04-15

---

## 1. 项目背景

开发一个社区论坛网站，为用户提供发帖、讨论、互动交流的平台。项目从零开始搭建，涵盖前后端完整开发流程，最终实现线上部署。

## 2. 项目目标

- 构建功能完善的论坛系统，支持用户发帖、评论、互动
- 实现管理后台，支持内容审核和用户管理
- 支持全文搜索，提升用户体验
- 构建响应式页面，兼容 PC 和移动端浏览器
- 预期承载 **1000 用户** 量级

## 3. 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| **游客** | 未登录用户 | 浏览帖子、浏览评论、搜索、查看用户主页 |
| **普通用户** | 已注册登录用户 | 游客权限 + 发帖、评论、点赞、收藏、管理个人资料 |
| **管理员** | 后台管理人员 | 所有权限 + 用户管理、内容审核、数据统计、分类管理 |

## 4. 功能需求

### 4.1 用户系统

#### 4.1.1 用户注册
- 用户通过 **用户名 + 邮箱 + 密码** 完成注册
- 用户名和邮箱需全局唯一
- 密码使用 BCrypt 加密存储
- 注册后自动分配普通用户角色

#### 4.1.2 用户登录
- 支持用户名/邮箱 + 密码登录
- 登录成功后返回 JWT Token
- Token 有效期内免登录，支持 Token 刷新

#### 4.1.3 个人资料
- 用户可修改：昵称、头像、个人简介
- 用户可修改密码（需验证旧密码）
- 头像支持图片上传

#### 4.1.4 个人主页
- 展示用户公开信息（昵称、头像、简介、注册时间）
- 展示用户发布的帖子列表
- 本人可查看自己的收藏列表

---

### 4.2 帖子系统

#### 4.2.1 发布帖子
- 用户需登录后才能发帖
- 帖子包含：**标题**、**内容**（富文本）、**分类**（必选一个）、**标签**（可选多个）
- 富文本编辑器支持：文字格式、图片上传/插入、链接、列表、代码块等
- 发帖时自动截取内容前 N 字作为摘要

#### 4.2.2 编辑帖子
- 仅帖子作者可编辑自己的帖子
- 编辑后记录更新时间

#### 4.2.3 删除帖子
- 帖子作者和管理员可删除帖子
- 删除帖子后同步删除相关评论、点赞、收藏数据

#### 4.2.4 帖子列表
- 首页展示帖子列表，支持分页
- 排序方式：最新发布（默认）、最多浏览、最多点赞、最多评论
- 筛选方式：按分类筛选、按标签筛选
- 置顶帖子在列表顶部展示
- 精华帖子有特殊标记

#### 4.2.5 帖子详情
- 展示帖子完整内容（富文本渲染）
- 展示作者信息、发布时间、更新时间
- 展示所属分类和标签
- 展示浏览量、点赞数、评论数、收藏数
- 进入详情页自动增加浏览量

---

### 4.3 分类/板块系统

#### 4.3.1 分类结构
- 采用一级分类结构（不嵌套）
- 每个帖子必须隶属一个分类
- 分类包含：名称、描述、图标、排序序号

#### 4.3.2 分类管理
- 仅管理员可创建、编辑、删除分类
- 分类页面展示该分类下的所有帖子

---

### 4.4 标签系统

#### 4.4.1 标签功能
- 用户发帖时可选择已有标签或创建新标签
- 每个帖子可关联多个标签
- 标签页面展示该标签下的所有帖子
- 提供热门标签展示（按使用次数排序）

---

### 4.5 评论系统

#### 4.5.1 评论结构（B站风格楼中楼）
- 采用 **两级评论** 结构：
  - **一级评论**：直接回复帖子的评论
  - **二级评论**：回复一级评论的子回复，显示在一级评论下方
- 二级评论展示格式：`@被回复用户 回复内容`
- 一级评论按时间排序（最新/最早）
- 二级评论按时间正序展示

#### 4.5.2 发表评论
- 需登录后才能评论
- 支持回复帖子（一级评论）和回复评论（二级评论）

#### 4.5.3 删除评论
- 评论作者和管理员可删除评论
- 删除一级评论时同步删除其下所有子回复

---

### 4.6 点赞功能

#### 4.6.1 帖子点赞
- 登录用户可对帖子点赞/取消点赞
- 每个用户对同一帖子只能点赞一次
- 实时更新帖子的点赞数

#### 4.6.2 评论点赞
- 登录用户可对评论点赞/取消点赞
- 每个用户对同一评论只能点赞一次
- 实时更新评论的点赞数

---

### 4.7 收藏功能

- 登录用户可收藏/取消收藏帖子
- 每个用户对同一帖子只能收藏一次
- 用户可在个人中心查看收藏列表
- 实时更新帖子的收藏数

---

### 4.8 搜索功能

#### 4.8.1 全文搜索
- 基于 **Elasticsearch** 实现帖子搜索
- 搜索范围：帖子标题、帖子内容、标签
- 搜索结果按相关度排序
- 搜索关键词在结果中 **高亮** 显示

#### 4.8.2 搜索建议
- 输入搜索关键词时提供自动补全建议
- 基于历史帖子标题和标签生成建议

---

### 4.9 管理后台

#### 4.9.1 数据统计
- 展示：用户总数、帖子总数、评论总数、今日新增帖子数等
- 数据概览仪表盘

#### 4.9.2 用户管理
- 查看所有用户列表（支持分页、搜索）
- 禁用/启用用户账号
- 设置/撤销管理员角色

#### 4.9.3 帖子管理
- 查看所有帖子列表（支持分页、搜索、筛选）
- 审核帖子（通过/隐藏）
- 设置/取消帖子置顶
- 设置/取消帖子精华
- 删除帖子

#### 4.9.4 分类管理
- 创建、编辑、删除分类
- 调整分类排序

#### 4.9.5 评论管理
- 删除违规评论

---

## 5. 非功能需求

### 5.1 响应式设计
- 页面需适配 PC 端和移动端浏览器
- 不需要开发原生 App
- 移动端优先保证核心功能可用性

### 5.2 安全性
- 密码加密存储（BCrypt）
- JWT Token 认证
- 接口权限控制（游客/用户/管理员）
- 防止 XSS 攻击（富文本内容过滤）
- 防止 SQL 注入（MyBatis-Plus 参数化查询）

### 5.3 性能
- 页面加载时间 < 3 秒
- 搜索响应时间 < 1 秒
- 图片上传限制大小（建议 5MB 以内）
- 帖子列表分页加载，每页 20 条

### 5.4 数据同步
- 帖子发布/修改/删除时自动同步到 Elasticsearch
- 点赞、评论、收藏等冗余计数实时更新

## 6. 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue 3 + Vite + Element Plus + Pinia + Vue Router + Axios + WangEditor 5 |
| 后端 | Spring Boot 3 + Spring Security + JWT + MyBatis-Plus |
| 数据库 | MySQL 8.0 |
| 搜索引擎 | Elasticsearch 8.x |
| 后端架构 | 多模块 Maven（forum-common / forum-pojo / forum-server） |

## 7. 约束与假设

- 用户量级预期 1000 人，无需考虑高并发场景
- 初期文件上传使用服务器本地存储，后续可迁移至 OSS
- 不需要通知系统（站内信、消息推送等）
- 不需要第三方登录（可后续扩展）
- 不需要邮箱验证注册（可后续扩展）
