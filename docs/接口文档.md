## 通用说明

### 统一返回格式

所有接口均返回以下 JSON 格式：

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 状态码，200=成功，其他=失败 |
| message | String | 提示信息 |
| data | Object | 返回数据，可能为 null |

### 常用状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或 Token 过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 认证方式

需要认证的接口需在请求头中携带 JWT Token：

```
Authorization: Bearer <token>
```

### 分页参数

支持分页的接口使用以下通用参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | Integer | 否 | 1 | 页码 |
| size | Integer | 否 | 20 | 每页条数 |

分页返回格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "records": [ ... ]
  }
}
```

## 1. 认证模块

### 1.1 用户注册

**POST** `/api/auth/register`

**请求体：**

```json
{
  "username": "testuser",
  "email": "test@example.com",
  "password": "123456"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | String | 是 | 用户名，3-50字符，唯一 |
| email | String | 是 | 邮箱，格式校验，唯一 |
| password | String | 是 | 密码，6-20字符 |

**成功响应：**

```json
{
  "code": 200,
  "message": "注册成功",
  "data": null
}
```

**错误响应：**

| code | message |
|------|---------|
| 400 | 用户名已存在 |
| 400 | 邮箱已被注册 |
| 400 | 参数格式不正确 |

## 4. 评论模块

### 4.1 获取帖子评论列表

**GET** `/api/posts/{postId}/comments`

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| postId | Long | 帖子ID |

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | Integer | 否 | 1 | 一级评论页码 |
| size | Integer | 否 | 20 | 一级评论每页条数 |
| sort | String | 否 | latest | 排序：latest/earliest/hottest |

**成功响应（B站风格两级评论）：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 50,
    "records": [
      {
        "id": 1,
        "content": "一级评论内容",
        "user": {
          "id": 1,
          "nickname": "用户A",
          "avatar": "https://oss.example.com/avatar/1.png"
        },
        "likeCount": 10,
        "isLiked": false,
        "createdAt": "2026-04-15 11:00:00",
        "replyCount": 3,
        "replies": [
          {
            "id": 10,
            "content": "二级回复内容",
            "user": {
              "id": 2,
              "nickname": "用户B",
              "avatar": "https://oss.example.com/avatar/2.png"
            },
            "replyToUser": {
              "id": 1,
              "nickname": "用户A"
            },
            "likeCount": 2,
            "isLiked": false,
            "createdAt": "2026-04-15 11:30:00"
          }
        ]
      }
    ]
  }
}
```

> 注：
> - 一级评论分页返回，每条一级评论下默认附带前 3 条二级回复
> - `replyCount` 表示该一级评论下的总回复数
> - 若需加载更多回复，可调用独立接口（通过 parentId 查询）

---

### 4.2 发表评论

**POST** `/api/posts/{postId}/comments`

> 🔒 需要认证

**请求体：**

```json
{
  "content": "评论内容",
  "parentId": null,
  "replyToUserId": null
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| content | String | 是 | 评论内容，1-1000字符 |
| parentId | Long | 否 | 父评论ID（回复评论时必填，一级评论不传） |
| replyToUserId | Long | 否 | 回复目标用户ID（回复二级评论时使用） |
