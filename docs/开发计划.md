## 项目概述

从零开发一个论坛网站，支持用户注册登录、发帖、评论、点赞收藏、搜索、标签、管理后台等功能。预计用户量 1000 人，需响应式适配移动端网页。

## 技术架构

### 架构总览

```
┌──────────────────────────────────────────────────────┐
│                     前端 (Vue 3)                      │
│  Vue 3 + Vite | Element Plus | Pinia | Vue Router    │
│  Axios | WangEditor 富文本编辑器                       │
└──────────────────────┬───────────────────────────────┘
                       │ REST API
┌──────────────────────▼───────────────────────────────┐
│                   后端 (Spring Boot 3)                │
│  Spring Security + JWT | MyBatis-Plus | Knife4j      │
│  Spring Data Elasticsearch | 文件上传 (本地/OSS)       │
└───────────┬──────────────────────────┬───────────────┘
            │ JDBC                     │ REST Client
┌───────────▼──────────┐  ┌────────────▼──────────────┐
│     MySQL 8.0        │  │   Elasticsearch 8.x       │
│   关系型数据存储       │  │     全文搜索引擎           │
└──────────────────────┘  └───────────────────────────┘
```

### 技术栈明细

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | Vue 3 + Vite | 最新版 Composition API |
| **UI 组件库** | Element Plus | 中文文档完善，生态成熟 |
| **状态管理** | Pinia | Vue 3 官方推荐 |
| **路由** | Vue Router 4 | 前端路由管理 |
| **HTTP 客户端** | Axios | 请求拦截、JWT 自动携带 |
| **富文本编辑器** | WangEditor 5 | 轻量、开源、中文友好 |
| **后端框架** | Spring Boot 3 | Java 17+ |
| **ORM** | MyBatis-Plus | MyBatis 增强版 |
| **认证授权** | Spring Security + JWT | 无状态令牌认证 |
| **API 文档** | Knife4j (Swagger) | 自动生成接口文档 |
| **数据库** | MySQL 8.0 | 关系型数据存储 |
| **搜索引擎** | Elasticsearch 8.x | 全文搜索，帖子标题+内容检索 |
| **构建工具** | Maven | 后端项目管理（多模块） |

## 数据库设计

### ER 关系图

```
USER ──1:N──> POST ──N:1──> CATEGORY
USER ──1:N──> COMMENT
USER ──1:N──> POST_LIKE
USER ──1:N──> COMMENT_LIKE
USER ──1:N──> FAVORITE
POST ──1:N──> COMMENT
POST ──1:N──> POST_LIKE
POST ──1:N──> FAVORITE
POST ──M:N──> TAG (通过 POST_TAG)
COMMENT ──1:N──> COMMENT (楼中楼)
COMMENT ──1:N──> COMMENT_LIKE
```

### 表结构详细设计

#### 1. `user` 用户表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| email | VARCHAR(100) | UNIQUE, NOT NULL | 邮箱 |
| password | VARCHAR(255) | NOT NULL | 密码(BCrypt加密) |
| nickname | VARCHAR(50) | | 昵称 |
| avatar | VARCHAR(255) | | 头像URL |
| bio | VARCHAR(500) | | 个人简介 |
| role | TINYINT | DEFAULT 0 | 0=普通用户, 1=管理员 |
| status | TINYINT | DEFAULT 1 | 0=禁用, 1=正常 |
| post_count | INT | DEFAULT 0 | 发帖数(冗余) |
| created_at | DATETIME | NOT NULL | 注册时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

#### 2. `category` 分类/板块表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 分类ID |
| name | VARCHAR(50) | UNIQUE, NOT NULL | 分类名称 |
| description | VARCHAR(255) | | 分类描述 |
| icon | VARCHAR(50) | | 图标 |
| sort_order | INT | DEFAULT 0 | 排序序号 |
| post_count | INT | DEFAULT 0 | 帖子数(冗余) |
| created_at | DATETIME | NOT NULL | 创建时间 |

#### 3. `post` 帖子表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 帖子ID |
| title | VARCHAR(200) | NOT NULL | 标题 |
| content | LONGTEXT | NOT NULL | 内容(HTML) |
| summary | VARCHAR(500) | | 摘要(自动截取) |
| user_id | BIGINT | FK, NOT NULL | 作者ID |
| category_id | BIGINT | FK, NOT NULL | 分类ID |
| view_count | INT | DEFAULT 0 | 浏览量 |
| like_count | INT | DEFAULT 0 | 点赞数(冗余) |
| comment_count | INT | DEFAULT 0 | 评论数(冗余) |
| favorite_count | INT | DEFAULT 0 | 收藏数(冗余) |
| is_top | TINYINT | DEFAULT 0 | 是否置顶 |
| is_essence | TINYINT | DEFAULT 0 | 是否精华 |
| status | TINYINT | DEFAULT 1 | 0=待审核, 1=正常, 2=隐藏 |
| created_at | DATETIME | NOT NULL | 发帖时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

> **注意：** 帖子发布/更新/删除时，需同步到 Elasticsearch 索引用于全文搜索。

#### 4. `comment` 评论表（支持B站风格楼中楼）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 评论ID |
| content | TEXT | NOT NULL | 评论内容 |
| user_id | BIGINT | FK, NOT NULL | 评论用户ID |
| post_id | BIGINT | FK, NOT NULL | 所属帖子ID |
| parent_id | BIGINT | FK, DEFAULT NULL | 父评论ID(NULL=一级评论) |
| reply_to_user_id | BIGINT | FK | 回复目标用户ID |
| like_count | INT | DEFAULT 0 | 点赞数(冗余) |
| status | TINYINT | DEFAULT 1 | 0=隐藏, 1=正常 |
| created_at | DATETIME | NOT NULL | 评论时间 |

> **楼中楼说明：** 一级评论的 `parent_id` 为 NULL，回复评论时 `parent_id` 指向被回复的一级评论，`reply_to_user_id` 记录具体回复的是哪个用户。

#### 5. `tag` 标签表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 标签ID |
| name | VARCHAR(30) | UNIQUE, NOT NULL | 标签名 |
| post_count | INT | DEFAULT 0 | 使用次数(冗余) |
| created_at | DATETIME | NOT NULL | 创建时间 |

#### 6. `post_tag` 帖子-标签关联表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| post_id | BIGINT | PK, FK | 帖子ID |
| tag_id | BIGINT | PK, FK | 标签ID |

#### 7. `post_like` 帖子点赞表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | BIGINT | PK, FK | 用户ID |
| post_id | BIGINT | PK, FK | 帖子ID |
| created_at | DATETIME | NOT NULL | 点赞时间 |

#### 8. `comment_like` 评论点赞表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | BIGINT | PK, FK | 用户ID |
| comment_id | BIGINT | PK, FK | 评论ID |
| created_at | DATETIME | NOT NULL | 点赞时间 |

#### 9. `favorite` 收藏表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | BIGINT | PK, FK | 用户ID |
| post_id | BIGINT | PK, FK | 帖子ID |
| created_at | DATETIME | NOT NULL | 收藏时间 |

#### 10. `operation_log` 操作日志表（管理后台）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 日志ID |
| user_id | BIGINT | FK | 操作人ID |
| action | VARCHAR(50) | NOT NULL | 操作类型 |
| target_type | VARCHAR(30) | | 目标类型(user/post/comment) |
| target_id | BIGINT | | 目标ID |
| detail | VARCHAR(500) | | 操作详情 |
| ip | VARCHAR(50) | | 操作IP |
| created_at | DATETIME | NOT NULL | 操作时间 |

## 前端页面规划

### 核心页面

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页 | `/` | 帖子列表、分类导航、热门标签、搜索框 |
| 登录 | `/login` | 登录表单 |
| 注册 | `/register` | 注册表单 |
| 帖子详情 | `/post/:id` | 帖子内容、评论区、点赞收藏 |
| 发布帖子 | `/post/create` | 富文本编辑器、选择分类、添加标签 |
| 编辑帖子 | `/post/edit/:id` | 编辑已发布的帖子 |
| 个人主页 | `/user/:id` | 用户信息、用户帖子列表 |
| 个人设置 | `/settings` | 修改资料、头像、密码 |
| 分类帖子 | `/category/:id` | 某分类下的帖子列表 |
| 标签帖子 | `/tag/:id` | 某标签下的帖子列表 |
| 搜索结果 | `/search?q=xxx` | 搜索结果列表 |

### 管理后台页面

| 页面 | 路由 | 说明 |
|------|------|------|
| 仪表盘 | `/admin` | 数据概览 |
