# 项目功能完成度清单

## 结论

当前项目的核心论坛主流程已经基本可用，包括用户注册登录、发帖、评论、点赞收藏、个人中心、设置页、通知中心等。

按照 `docs/开发计划.md` 与 `docs/需求文档.md` 对照现状，尚未完成的重点主要集中在：

- Elasticsearch 搜索完整方案
- 管理后台能力
- 若干页面与筛选闭环
- 部分工程化与部署项

## 已完成

### 基础架构

- 后端多模块 Maven 工程已搭建完成
- 前端 Vue 3 + Vite 工程已搭建完成
- 统一返回结构 `Result<T>` 已落地
- JWT 鉴权与路由登录保护已接入

### 用户系统

- 用户注册
- 用户登录
- 获取当前登录用户信息
- 修改个人资料
- 修改密码
- 个人主页
- 我的帖子
- 我的收藏
- 我的动态

### 帖子系统

- 帖子发布
- 帖子详情
- 帖子删除
- 帖子更新接口
- 首页帖子列表
- 分类筛选
- 基础排序
- 文件上传

### 评论与互动

- 两级评论
- 删除评论
- 帖子点赞
- 评论点赞
- 帖子收藏

### 其他功能

- 分类列表
- 热门标签
- 发帖时新建标签
- 通知中心
- 评论/回复/点赞/收藏通知

## 部分完成

### 搜索功能

- 已有搜索页
- 当前搜索实际复用帖子分页接口
- 后端仅对标题和摘要做普通 `like` 查询
- 前端高亮为本地正则替换，不是搜索引擎返回高亮

### 标签系统

- 标签列表与热门标签已实现
- 前端已传 `tagId`
- 后端帖子分页尚未按 `tagId` 过滤
- 热门标签点击后的帖子筛选链路未真正打通

### 排序能力

- 后端支持 `latest`、`hot`、`most_liked`、`most_commented`
- 前端首页当前只暴露了前三项，缺少“最多评论”入口

### Token 刷新

- 后端存在 `/api/auth/refresh`
- 当前接口仍是占位实现，未返回新 token
- 前端未接入 token 刷新逻辑
